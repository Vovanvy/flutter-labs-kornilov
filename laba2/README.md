# Лабораторная работа 2 — знакомство с Dart

Программа загружает демонстрационный список расходов, выводит его,
считает общую сумму и расходы на еду. Весь код — в `bin/laba2.dart`.
Это консольная работа: по заданию второй лабораторной Flutter-интерфейс не требуется.

## Требования задания

| Требование | Где используется |
| --- | --- |
| Класс с полями и методами | `Expense`: `name`, `amount`, `category`, `printInfo()` |
| Enum | `Category` с категориями `food`, `transport`, `study` |
| Циклы | Два цикла `for` для подсчёта расходов |
| Generics | `List<Expense>` и `Future<List<Expense>>` |
| Анонимная функция | `(expense) => expense.category == Category.food` внутри `where` |
| Future | `loadExpenses()`, `async`, `await`, имитация задержки загрузки |
| Extension | `CategoryName`: геттер `title` возвращает русское название категории |

```powershell
dart pub get
dart analyze
dart run
```

Ожидаемый вывод:

```text
Загружаем расходы...
Обед: 250 руб. (Еда)
Автобус: 60 руб. (Транспорт)
Тетрадь: 100 руб. (Учёба)
Ужин: 300 руб. (Еда)

Всего потрачено: 710 руб.
Из них на еду: 550 руб.
```

Чтобы изменить данные, отредактируйте список в `loadExpenses()`.
